WOLFY – SHEEP ENEMY SPRITES

Separate animation frames, no combined sprite sheet.

All PNG files:
- exactly 128 x 128 pixels
- RGBA
- transparent background
- common character scale
- common anchor: X=64, ground Y=120

Animations:
idle  6 frames
walk  6 frames
run   8 frames
jump  4 frames
fall  4 frames
land  4 frames
hurt  4 frames
death 6 frames

Directory layout:
assets/images/enemies/sheep/
  idle/00.png ... 05.png
  walk/00.png ... 05.png
  run/00.png ... 07.png
  jump/00.png ... 03.png
  fall/00.png ... 03.png
  land/00.png ... 03.png
  hurt/00.png ... 03.png
  death/00.png ... 05.png

The frames are intended to be loaded individually by the same type of
animation system used for Wolfy.
