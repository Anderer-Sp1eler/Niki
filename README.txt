WOLFY – IDLE FIX v3

Korrektur:
Die Idle-Frames 00–05 sind jetzt pixelgenau identisch. Damit bleibt Wolfy
im Stillstand vollständig stabil: keine Größenänderung und kein Verschieben
um einzelne Pixel.

Das ist bewusst eine technische Stabilisierung. Eine echte "Atmen"-Animation
kann später mit gezielt konstruierten Frames ergänzt werden, ohne die
Boden-/Positionsverankerung zu verändern.

Alle Frames bleiben exakt 128 x 128 Pixel und verwenden Alpha-Transparenz.
